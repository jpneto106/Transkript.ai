Build do ffmpeg incluído no Transkript.ai v4
============================================

Este arquivo documenta QUAL binário o programa espera encontrar em
<app>/ferramentas/ffmpeg/bin/. Os valores aqui precisam bater exatamente com
o que o `instalador/baixar_ffmpeg.py` baixa; qualquer divergência é
intencional e exige atualizar dos dois lados.

Origem
------
Repositório: https://github.com/BtbN/FFmpeg-Builds
Asset      : ffmpeg-master-latest-win64-lgpl-shared.zip
URL direto : https://github.com/BtbN/FFmpeg-Builds/releases/download/latest/
             ffmpeg-master-latest-win64-lgpl-shared.zip
Licença    : LGPL 2.1 ou superior (build sem codecs GPL)
Plataforma : Windows 10/11, 64 bits

Identificação esperada
----------------------
SHA-256    : 326b627e9e7267fd2d987f3455b1d0f5a0a5e116841e27db707ec9a04d6b4873
Tamanho    : ~67 MB comprimido; ~200 MB descompactado em bin/

Como o app usa
--------------
- `ffprobe.exe` — lê a duração do arquivo (nucleo/midia.py::duracao_segundos)
- `ffmpeg.exe`  — converte para PCM mono 16 kHz, signed 16-bit little-endian
                  (nucleo/midia.py::carregar_audio)
Nada além disso. Codificadores de vídeo (x264, x265, AV1) e filtros pesados
não são chamados.

Atualização
-----------
Para trocar a versão do ffmpeg, edite os valores em `baixar_ffmpeg.py` (URL e
SHA-256) e atualize também este arquivo. O `empacotar.py` chama o script
automaticamente quando os binários não estão presentes.

Última atualização: v4.0.0 (julho/2026).
